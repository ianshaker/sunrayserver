# yandexmail — чтение Яндекс.Почты по IMAP

Второй источник писем рядом с Gmail. **Только чтение.** Пока рубильник выключен,
модуль не подключается к почте вовсе и ни на что не влияет.

Gmail-ветка (`postamails/`) продолжает работать как раньше: этот модуль её не
трогает и не заменяет до отдельного решения владельца.

## Гарантии «только чтение» — в устройстве, а не на словах

| Гарантия | Как обеспечена |
|---|---|
| Папка открывается без права записи | `getMailboxLock(..., { readOnly: true })` → библиотека шлёт `EXAMINE` |
| Сервер подтвердил режим чтения | `guard.assertMailboxOpenedReadOnly` прерывает работу, если это не так |
| Письма не помечаются прочитанными | выборка идёт через `BODY.PEEK` |
| Команд изменения нет в самом коде | `guard.scanModuleForMutations()` ищет их в исходниках модуля |
| Снятый режим чтения останавливает модуль | `guard.assertReadOnlyModeEnabled()` бросает ошибку до подключения |
| Пароль не попадает в логи | библиотечный лог выключен, тексты ошибок чистятся `safeMessage` |

## Устройство

| Файл | Зачем |
|---|---|
| `config.js` | все переменные окружения в одном месте; наружу отдаёт настройки без пароля |
| `imap/guard.js` | защита режима чтения и проверка исходников на запрещённые команды |
| `imap/client.js` | единственная дверь наружу: `withReadOnlyMailbox(handler)` |
| `imap/fetch.js` | заголовки (дёшево) и письмо целиком (только для нужных) |
| `imap/authRetry.js` | мягкие повторы, пока Яндекс включает новый пароль приложения |
| `health/check.js` | самопроверка с человеческим объяснением, что не так |
| `run-health-check.js` | ручной запуск проверки |
| `index.js` | точка сборки; при подключении ничего не запускает |

## Переменные окружения

Полный список — в `.env.example` в корне сервера. Обязательные: `YANDEX_IMAP_USER`
и `YANDEX_IMAP_PASSWORD` (пароль приложения Яндекса, задаётся только в настройках
Render). Остальные имеют значения по умолчанию.

Рубильники: `YANDEX_IMAP_ENABLED` (по умолчанию `false`),
`YANDEX_IMAP_SHADOW_MODE` (по умолчанию `true`), `YANDEX_IMAP_READ_ONLY`
(по умолчанию `true`, снимать нельзя).

## Проверка

```
node yandexmail/run-health-check.js
```

Подключается, открывает папку на чтение, показывает поколение ящика, число писем
и последние пять заголовков. Ничего не меняет.

## Чего модуль не делает

- не помечает, не перемещает, не удаляет письма и не отправляет почту;
- не заводит заявок и не пишет в Telegram — этим занимается общая обработка;
- не запускается сам: ни таймеров, ни соединений при подключении модуля.
